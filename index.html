CSS Overflow Demonstration

Explore how CSS handles overflowing content.

1. Overflow: Visible

This is a long paragraph demonstrating visible overflow. The content continues outside the fixed-height container. More text is added to make the content overflow the box.

2. Overflow: Hidden

This is a long paragraph demonstrating hidden overflow. The content continues beyond the fixed-height container. The extra content is clipped and cannot be seen.

3. Overflow: Auto

This is a long paragraph demonstrating automatic overflow. When the content exceeds the container height, a scrollbar appears as needed so users can read the remaining text. More content helps demonstrate scrolling.

4. Overflow: Scroll

This is a long paragraph demonstrating scroll overflow. A scrollbar is provided so users can access the extra text. This content extends beyond the available height.

5. Fixed Layout Example

This container has a fixed height and automatic overflow. Adding more content will make the container scroll instead of allowing the text to cover other sections of the page.
